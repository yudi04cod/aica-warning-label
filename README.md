One funny line for make.fun's "Warning Label for Humans: One Line, Big
Laugh": the single-line safety warning label that should come printed on
every human being, 160 characters or fewer — deadpan product-label
wording, a true-about-people observation, and the punch landing in the
last few words.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–160 characters, not only whitespace), and writes the same bytes on
every run.
